# Desktop pixel-perfect QA

Дата проверки: 25 июля 2026.

## Метод

Выполнены повторные screenshot-overlay проверки в Chromium. Каждый финальный WebP выводился браузером в реальном viewport и сравнивался с утверждённым PNG попиксельно. Проверены ширины 1920, 1440 и 1280 px.

## Итог

Минимальное совпадение по всем 18 проверкам — **99,1948%**. Целевой порог пользователя 95% превышен.

| Экран | 1920 px | 1440 px | 1280 px |
|---|---:|---:|---:|
| Hero | 99,3570% | 99,3893% | 99,4069% |
| Рост выручки и автоматизация | 99,2551% | 99,3035% | 99,3257% |
| Масштабирование направления | 99,6227% | 99,5956% | 99,6048% |
| Развитие интернет-магазина | 99,1948% | 99,2408% | 99,2744% |
| Запуск нового бизнес-юнита | 99,5183% | 99,4739% | 99,4883% |
| Контакты | 99,3688% | 99,3815% | 99,3979% |

Небольшое отличие hero включает маски, закрывающие декоративные цифры `01 / 02 / 03` по требованию пользователя. Остальная разница обусловлена только WebP-компрессией и браузерной интерполяцией.

## Технические проверки

- Внешние поля браузера отсутствуют.
- Соотношение сторон каждого утверждённого экрана сохраняется.
- Изображения не растягиваются независимо по ширине и высоте.
- `object-fit: cover` не используется.
- Утверждённые data-art объекты не перерисовываются CSS.
- Нет новых фотографий и выдуманных KPI.
- Навигационные зоны и CTA поверх экранов кликабельны.
- Скрытый HTML-текст сохраняет семантику и доступность.
- Desktop зафиксирован отдельно; mobile будет собираться следующим этапом и не изменит desktop.
